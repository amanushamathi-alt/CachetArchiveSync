## 10. Reviewer Notes

- **N1 — Process disclosure (adequate).** The fix was applied before the spec existed. The spec says so in the Implementation Log "Process note" and in the §15 Author row, and the file timestamps agree: CSS at 13:30:25, spec at 13:31:55. For SOC 2 change traceability, the disclosure is adequate. The record is complete once the §16 checkboxes are ticked and this review is signed off in §15.
- **N2 — Small inaccuracy in spec §1.** §1 says `--cachet-header-text` is "white". It is `#D7DEE9` (`app.css:24`), a very light grey-blue. The header is white because the scoped `.cachet-header-bar` (`MainLayout.razor.css:30`) overrides the navy `app.css:124`. Before the fix, the contrast was about 1.3:1, which was effectively invisible. That supports the bug report. The point is cosmetic.
- **N3 — The "matches `.cachet-header-btn`" claim is approximate.** `.cachet-header-btn` (`MainLayout.razor.css:90-98`) has no `font-weight: 600`. MainLayout's current markup does not render it either; `TaskManagerBadge` uses only `cachet-header-btn-disabled`. In practice the Sign Out button keeps app.css's `border-radius: 3px`, `padding: 5px 11px` and `font-size: 11.5px` (`app.css:189-191`). The look is a navy outline, but the box metrics are not identical to `.cachet-header-btn`. Not a defect.
- **N4 — The CSS comment does not cite the spec ID.** `MainLayout.razor.css:127` says "Sign Out visibility fix (2026-10-01)". It does not reference `CAS-042`, unlike neighbouring rules (for example "CAS-025 §3/§8.1" and "CAS-027 §3/§8.7"). The comment was written before the spec existed. Adding "CAS-042" later would improve traceability. Optional.
- **N5 — Unattributed `Login.razor` write (not CAS-042).** `Components/Pages/Login.razor` was written at 2026-10-01 13:28:09. It is not in the CAS-042 §5 or §6 tables, its content has only CAS-021 markers, and it contains no styling or Sign Out content. This is the same file and pattern as the open N-SCOPE-2 in `CAS-039.review.md`, which recorded a write at 13:24:06. Without VCS this cannot be settled. The owner should confirm the write is a no-op or link it to a change record.
- **N6 — Open question §14 still stands.** The global `app.css` `.cachet-sign-out-btn` rule now has no consumer that uses its dark-header styling, because MainLayout's scoped rule overrides it. The owner may want to consolidate it in a separate change.
