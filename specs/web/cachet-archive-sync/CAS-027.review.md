## 10. Reviewer Notes

1. **Graphify infrastructure gap (not a defect in this spec's work):** as detailed in §6 above, the
   vendored graph has zero `.razor` coverage and stale/mismatched absolute paths from a different
   checkout root. Recommend re-running `graphify update .` from this project's actual current path once
   Razor-file extraction is confirmed supported (or documenting explicitly that Razor files are out of
   graphify's scope for this stack), so future Web-layer specs don't waste a step discovering this.
2. **Spec text gap, correctly caught by the implementer:** §8.3's own code snippet for `TaskId` omits
   the `[Parameter]` attribute required alongside `[SupplyParameterFromQuery]` for query-string binding
   to actually occur — without it, the parameter would always bind `null`. Both `KeywordSearch.razor`
   and `ODriveSyncContentScan.razor` correctly include `[Parameter]` with an inline comment flagging this
   as a necessary correction rather than a scope change. Worth folding back into CAS-027 §8.3's snippet
   itself so a future reader doesn't copy the incomplete version literally.
3. **V1's "exactly four columns" test asserts 5 `<th>` elements** (4 named + 1 empty for the row-action
   column), consistent with this codebase's established `QuarantineQueueModal.razor` convention of an
   unlabeled leading/trailing action column. This is a reasonable, tested interpretation and not flagged
   as a gap, but the spec's V1 wording could be tightened in a future revision to explicitly allow for an
   unlabeled action column, avoiding any ambiguity for the next reviewer.
4. `CAS-026` (the blocking API dependency per §0 point 1/§15) is present and functional —
   `TaskManagerController.cs`'s four read-side actions exist, are wired to real services, and were
   independently exercised (indirectly, via the fake-handler-backed Web tests) without issue. `CAS-026`
   itself carries `status: review` / verdict `APPROVED WITH NOTES` in its own review report, consistent
   with this spec no longer being blocked.
