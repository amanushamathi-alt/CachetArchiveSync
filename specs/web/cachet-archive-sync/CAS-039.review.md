**SC-15 CSS assessment (read-only, no browser).**

What supports one shared bottom line:
- The scoped `.cachet-toolbar` sets `align-items: flex-end`, `height: auto`, `min-height: 52px`, and 8px top / 14px bottom padding (`KeywordSearch.razor.css:199-205`). The scoped selector `.cachet-toolbar[b-…]` (0,2,0) outranks app.css `.cachet-toolbar` (0,1,0), which is `align-items: center; height: 52px` (`app.css:263-272`). The scoped rule therefore wins, and every direct flex item is bottom-aligned.
- **Search group:** a flex column (`:207-215`) whose last in-flow child is the term input (Keyword mode) or the date row with its input wrappers (Date mode). Its bottom edge is therefore the input's bottom edge in both modes. The 12px term margin is gone (`:217-222`).
- **Hints:** the V1 hint (`app.css:307-314`, absolute under `.cachet-toolbar-search`, which is `position: relative`) and the date hints (`.cachet-ks-date-hints`, absolute under the `position: relative` search group, `:232-241`) are out of flow. They cannot lift the controls.
- **Bucket / Extension:** each is one inline-flex item with `align-items: center` (`:226-230`). The item's box ends at the select's bottom, because the select (about 28px) is taller than the 11px label.
- **Right-hand controls:** the Search button, Quarantine Queue and Audit Log buttons are direct flex items. `TaskManagerBadge` renders a bare `<button>` plus a `.cachet-visually-hidden` span that is `position: absolute` (`TaskManagerBadge.razor:10-21`, `app.css:952`). Both are direct flex items of the page's toolbar, so they are bottom-aligned too. The badge is unchanged (2026-09-28).

Residual observations for the manual check (cosmetic, not failures):
1. **Only the bottoms line up.** Control heights differ: the input is about 33px; the select about 28-29px; the scoped Search and Quarantine buttons about 33px (`0.6rem` padding); the `.cachet-btn` Task Manager and Audit Log buttons about 30px. Tops will be staggered by a few pixels. This meets the spec's "one shared bottom line".
2. **The Date-mode toolbar is taller.** The From/To labels sit above the date inputs, about 18px more. With `flex-end`, the shared line and everything below the toolbar (action bar, panels) move down by that amount when switching to Date mode. §2.6c allows "beyond the date fields appearing or disappearing". The reviewer reads that as covering this, but the manual check should confirm it is acceptable.
3. **Hint room.** The 14px bottom padding is sized for one 10.5px hint line. Several date hints are laid out in a single `nowrap` row, so they cannot overflow vertically. On a narrow viewport they may overflow horizontally.
