## 10. Reviewer Notes

- Documentation staleness outside declared scope (non-blocking): .claude/skills/sqlserver-dapper/SKILL.md line 50 still describes dbo.report as an existing table ("generated-report metadata... PDF/XLSX file paths"). This file was not listed in the spec's Files to Change or Files NOT to Change sections, so its being unchanged is not a scope violation, but it is now factually incorrect post-CAS-015 (the table is dropped). Recommend a follow-up edit, analogous to the .claude/skills/reporting-pdf-xlsx/SKILL.md correction this spec did make.
- The spec's open-question resolutions were owner-confirmed, not implementer-assumed: all six checkboxes in the spec's Open Questions section carry an explicit "resolved 2026-09-22 (owner)" annotation with the owner's rationale recorded inline, consistent with the Verification Plan's requirement that the implementer not silently decide open points. No evidence was found of the implementation deviating from any of the six resolved positions (one-format-per-request, no bundled-both-formats response, preview-endpoint deferral, accepted synchronous-large-dataset risk, no orphaned-row backfill, no API versioning).
- format model-binding edge case: ReportGenerationRequest.Format is a C#-required record property. The V7 "missing format" test (Test_V7_MissingFormatReturnsValidationError) exercises an empty-string Format value rather than an actually-absent JSON field, with an explicit code comment acknowledging that required is a compile-time-only guard, not a wire-level guarantee. This is a reasonable and honestly-documented test design choice (a truly missing field would likely be intercepted by ASP.NET Core's own model-binding/[ApiController] automatic 400 before the controller action body executes at all, which is arguably a stronger and different validation path than the one V7 describes) -- flagged only as an observation, not a defect, since the empty-string case is a valid, distinct way to fail V7's rule and the test's own comment is transparent about the distinction it is and is not proving.
