### Backslash-escape fix verification

Both `Database/migrations/20261004_220000__CAS-047-search-modes.sql:58` and `Database/CachetArchiveSync/Stored-Procedures/dbo.search_result_filename_ins.sql:58` contain `REPLACE(REPLACE(REPLACE(REPLACE(@trimmed, N'\', N'\\'), N'%', N'\%'), N'_', N'\_'), N'[', N'\[')` with `ESCAPE N'\'` at line 86. Escape character is doubled first (correct order). `@escaped` is `NVARCHAR(800)`, enough for 4x expansion of a 200-char term. `Test_SC3_FilenameInputBackslashIsLiteral` seeds `x/xa\by.txt` and `x/xab-y.txt`, searches `a\b`, and asserts only the literal row is stored; it passes against the real DB.
